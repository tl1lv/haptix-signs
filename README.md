# HAPTIX — مكتبة لغة الإشارة

أهم 1366 كلمة في الحياة اليومية بفيديو مترجم لغة إشارة حقيقي، بعد إزالة الخلفية وضغط الحجم.
يستخدمها نظام **HAPTIX** (سوار اهتزازي ذكي للصم وضعاف السمع): عندما يسمع النظام كلمة، يهتز السوار وتظهر إشارتها.

## المصدر والإذن
المقاطع الأصلية من **مكتبة لغة الإشارة السعودية** — [sshi.sa](https://sshi.sa) — التابعة لـ **الجمعية السعودية للإعاقة السمعية**،
وتُستخدم في HAPTIX **بإذن من الجمعية**، لأغراض تعليمية غير ربحية. جميع حقوق المقاطع الأصلية محفوظة للجمعية.

## الملفات
| الملف | الوصف |
|---|---|
| `index.json` | فهرس الكلمات: المفتاح المطبّع ← رقم الإشارة، والحروف للتهجئة |
| `v/{id}.webm` | فيديو شفاف (VP9) لمتصفحات كروم وأندرويد |
| `v/{id}-hevc.mp4` | فيديو شفاف (HEVC) لسفاري والآيفون |
| `v/{id}.webp` | صورة مصغّرة |

**طريقة التجهيز:** إزالة الخلفية بنموذج RobustVideoMatting، ثم قصّ الإطار على جسم المترجم، ثم ضغط الفيديو.
